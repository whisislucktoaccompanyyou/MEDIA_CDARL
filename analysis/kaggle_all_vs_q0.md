# 全量与 EyeQ Q0 合成结果对比

Written for: 查看这次测试结果的人。

测试输入是 `test_input`，10 对图（id 21–30），seed=2026。两边都是已有 100k 权重，没有重新训练。

| 目录 | 是什么 |
| --- | --- |
| `test_output/kaggle_all_100k` | 全量权重的原始合成，无亮度对齐 |
| `test_output/kaggle_eyeq_q0_100k（8k优质图像）` | Q0 权重的原始合成，无亮度对齐 |
| `test_output/kaggle_all_100k_match` | 同一全量权重，另存亮度对齐图 |
| `test_output/kaggle_eyeq_q0_100k_match` | 同一 Q0 权重，另存亮度对齐图 |

拼图从左到右：原图、血管 mask、模型直接输出、亮度对齐后的图。看模型本身用第三张。第四张是后处理，不是新模型。

## 怎么读数

只比较模型自己的输出（`raw_*`）。亮度对齐（`matched_*`）单独看，不拿来选权重。

- `raw_fov_mae`：视盘内和原图的平均灰度差，越小越接近原图亮度。
- `raw_fov_mean_gap`：合成图比原图暗多少，越接近 0 越好。负值表示更暗。
- `raw_fov_corr`：和原图像素明暗是否同向，越大越像。
- `raw_vessel_contrast`：血管比背景暗多少。眼底血管应更暗，越负越清楚。
- `raw_edge_grad_ratio`：血管边缘比背景锐多少，越大越贴 mask。
- `raw_disc_circularity`：圆盘圆不圆。原图是 0.606，因为视盘贴在左缘，圆是缺的，所以只做两边互比，不和 1 比。
- `raw_disc_bulge`：圆盘超出拟合椭圆的比例，越小越没有鼓包。
- `condition_change_mae`：同一噪声下把 mask 水平翻转，输出变多少。越大说明生成器越在用血管条件。
- `cycle_dice`：合成图再送回自己的分割器。两边都是 0，不能用来选模型。

## t=200，10 张图的均值

| 指标 | 全量 | Q0 | 谁更好 |
| --- | ---: | ---: | --- |
| raw_fov_mae | 60.06 | 26.57 | Q0 |
| raw_fov_mean_gap | -58.65 | -8.04 | Q0 |
| raw_fov_corr | 0.657 | 0.706 | Q0 |
| raw_vessel_contrast | -5.01 | -1.58 | 全量 |
| raw_edge_grad_ratio | 2.13 | 1.78 | 全量 |
| raw_disc_circularity | 0.890 | 0.851 | 全量 |
| raw_disc_bulge | 0.0059 | 0.0104 | 全量 |
| condition_change_mae | 0.0257 | 0.0471 | Q0 |
| cycle_dice | 0 | 0 | 都不能用 |

图见 [compare_t200.html](compare_t200.html)，用浏览器打开。

## 亮度对齐没有让模型变好

对齐对象是同一张原图的眼底圆盘，只做直方图匹配，不改权重。全量 t=200：

| | 对齐前 | 对齐后 |
| --- | ---: | ---: |
| 视盘内 MAE | 60.06 | 11.70 |
| 均值差 | -58.65 | 0.08 |
| 圆形度 | 0.890 | 0.755 |
| 鼓包 | 0.0059 | 0.0094 |

平均亮度靠近了，圆盘和边缘被拉脏了。所以第四张不能当模型改进。

## 结论

Q0 更亮，灰度更接近原图，对 mask 翻转也更敏感。全量更暗，但血管对比更清楚，圆盘更圆，鼓包更小。几何比亮度难补，所以仍建议以全量权重为主，亮度不要用这次的直方图匹配去硬拉。

t=800 和 t=1600 的逐项均值在各自目录的 `synthesis_report.json` 里，字段名与上表相同。这次文档里的表是 t=200。
