# 彩色输出：在现有灰度模型旁边加一个颜色头

## 先回答两个问题

要重新训练，但只训新加的颜色头。现在的扩散网络和 SPADE 先冻结，旧权重原样加载，不覆盖。

颜色头不替换现有模型。它接在 SPADE 后面，读 SPADE 已经算好的特征，另外输出两个颜色通道。亮度仍由现在的生成器决定。

## 现在的模型在做什么

推理时读一张灰度眼底，加噪，扩散网络预测噪声，再和血管条件一起送进 SPADE。SPADE 最后一层只出 1 个通道，也就是现在看到的灰度合成图。

```text
灰度参考图
    │
    ▼
加噪 ──► 扩散网络 ──► 噪声预测
                          │
                          ▼
                    拼上血管条件
                          │
                          ▼
                       SPADE
                          │
                          ▼
                    1 通道灰度图
```

颜色不在这条链路里。配置里的 `channels` 是 1，`SPADEGenerator(2, 1)` 的第二个参数也是 1。把配置改成 3，旧权重对不上，等于从头训。

## 加上颜色头之后

眼底颜色用 Lab 表示。L 是亮度，a、b 是颜色。L 继续用现有生成器。颜色头只预测 a 和 b。保存时把三通道拼起来，转成 RGB。

```text
彩色参考图
    │
    ├─ 只取亮度 L ──────────────► 现有路径（冻结）
    │                                  │
    │                                  ▼
    │                            扩散网络 → SPADE → L
    │                                  │
    │                                  │  SPADE 的中间特征
    │                                  ▼
    └─ 这张图自己的 a、b  ◄──损失──  颜色头（新的，只训这一块）
                                       │
                                       ▼
                                  预测的 a、b
                                       │
                         L + a + b ──► RGB
```

关联只有一处：颜色头的输入是 SPADE 已经算好的特征，不是重新读原图。所以它知道视盘在哪、血管在哪，但改不了这些结构。

## 训练时谁动、谁不动

| 部分 | 这一轮 |
| --- | --- |
| 扩散网络 | 冻结，加载现有权重 |
| SPADE | 先冻结 |
| 判别器、对比损失 | 不动，仍只看灰度和血管 |
| 颜色头 | 新加，从头训 |

学习率 `1e-5`，batch 仍是 1。损失只算在眼底圆内的 a、b 上，用 L1。权重设得很小，避免为了颜色去改亮度。

不要用 RGB 的 L1 或 L2。那种损失会为了平均颜色把血管抹平。

## 数据

颜色头用的是现有生成模型的训练图，不是另找一个小数据集。

现有权重是 `experiments/CDARL_kaggle_quality_261111_093624`，训练图来自 `data/kaggle`，大约 3 万张。训练时这些图被转成了灰度，所以模型只见过 L。只要 `data/kaggle/extracted/train` 里的原图还是彩色 JPEG，同一张图就同时有：

- 灰度 L，已经用来训过生成模型
- 彩色原图里的 a、b，这次当颜色头的目标
- 这张图自己的血管，当条件

`DomainB_FP` 只有 619 张，只是其中一个彩色来源，不是颜色头的训练集。`data/` 下其他还保留彩色原图的数据集也可以加进来，但要和对应的灰度、血管配成同一张图。

分形掩膜没有对应的彩色照片，不能用来训颜色头。已经转成单通道、原图没有保留的数据也不能用。

另存一套颜色训练清单，不覆盖现在的灰度训练集，也不改现有权重。

## 什么时候算训完

先看两件事：

1. 生成图的 L 和现在的灰度结果一致。血管没有变糊，视盘还是亮的。
2. a、b 跟着这张参考图走，而不是所有图都同一个红。

两件都满足，就可以停。如果还想让颜色和结构贴得更紧，再把 SPADE 解码端用更小的学习率放开，扩散网络继续冻结。血管一旦变糊，就把颜色损失的权重降下来，不要继续放开。

## 和现在那个上色脚本的差别

| | `colorize_synthesis.py` | 颜色头 |
| --- | --- | --- |
| 要不要训练 | 不要 | 要，只训新头 |
| 颜色从哪来 | 命令行指定的一张彩照 | 每张图自己的彩照 |
| 和模型的关系 | 模型跑完后再贴 | 接在 SPADE 后面，一起出图 |
| 结构会不会变 | 不会 | 冻结时不会 |

如果所有图共用一种红色可以接受，脚本已经够了，不必训。只有希望每张合成图带上它自己那张参考图的颜色时，才值得加这个头。

## 顺序

是这个顺序，不是同时训：

```text
1. 生成模型已经训完
   experiments/CDARL_kaggle_quality_261111_093624
        │
        │  冻结，不再更新
        ▼
2. 旁边加一个颜色头
   读 SPADE 的特征，只预测 a、b
        │
        ▼
3. 保存时 L + a + b 转成 RGB
```

生成模型负责结构和亮度。颜色头负责这张参考图自己的颜色。两者只在 SPADE 特征这一处相连。
